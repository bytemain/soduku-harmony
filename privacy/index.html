隐私政策

这份说明介绍不错的数独如何处理应用中的数据，以及您可以如何管理这些数据。

生效及更新日期：2026年11月3日 · 适用范围：不错的数独 HarmonyOS 手机、智能手表应用及本官网

一、运营者与适用范围

不错的数独由杭州幻橙网络科技有限公司提供。本政策适用于本应用的离线数独功能及本官网。应用无需注册账号，不要求您为游玩提供姓名、电话号码、位置或支付信息。

隐私咨询及支持邮箱：support@oranix.cn。常见问题请查看支持页面。

二、应用处理哪些数据

数据或能力 用途与处理方式
题目与游戏进度 题面、已填数字、候选笔记、用时、错误记录及撤销记录等保存在设备本地，用于继续游戏。手机版还在本地保存逐步操作、检查点名称与分支路线记录，用于预览和恢复不同解题进度；这些记录不会上传至开发者服务器。
题库进度、统计和设置 完成情况、游戏历史及显示和布局偏好等保存在设备本地，用于统计和恢复设置。
剪贴板 仅在您主动点击导入时读取相关文本以解析题目或种子；点击复制时写入您选择的题目或种子。应用不在后台监视剪贴板。
可选握持手状态 自动左右手布局默认关闭。开启后，应用使用系统提供的握持状态在本地调整布局，不用于识别个人；关闭或进入后台时停止订阅。不支持此能力的设备可手动调整。
本地诊断日志 应用可能写入系统本地日志以帮助定位运行错误，没有主动上传诊断日志的实现。

三、联网、第三方服务与备份

当前应用没有开发者业务服务器，没有登录、支付、广告或分析上报服务，未接入用于这些目的的第三方 SDK。应用使用 HarmonyOS 系统能力提供存储、剪贴板、可选握持感知等功能。

应用允许系统备份与恢复。备份是否开启、备份位置、传输方式和保留时间由设备系统服务及您的设置决定。因此，本地保存不意味着系统备份永不传输数据；请结合您使用的系统服务说明管理备份。

四、数据保留与您的选择

游戏进度、统计和设置保留在设备上，直至被覆盖、清除或随应用卸载而删除。您可通过系统应用管理清除本应用数据；这会导致本地进度和设置丢失。系统备份副本需按系统备份服务的方式管理。

您可在设置中关闭自动左右手布局；不使用导入或复制功能时，应用不会为这些功能访问剪贴板。开发者业务服务器不持有您的本地数独进度，无法从服务器读取或恢复这些记录。

您可通过上述邮箱就数据处理请求说明或协助，或请求访问、更正、删除您向客服提供的信息。若您主动发送邮件，邮件地址、正文和附件将用于处理及回复该请求，并仅在提供支持、解决相关问题及满足适用要求所需的期限内保留；请不要发送密码、证件、无关个人信息或完整的敏感系统日志。

五、未成年人

未成年人可在监护人指导下使用本应用。应用不为游玩要求提供身份、联系方式或支付信息。商店最终年龄分级以应用市场展示为准。

六、本官网

我们的网页代码不提供账号、广告或分析服务，不设置追踪 Cookie；字体和图片使用本地资源或设备自带资源。页面内规则示意仅在浏览器中交互，不会上传您的操作。

本官网使用 GitHub Pages 托管。GitHub 会为安全目的记录访问者 IP 地址，是否登录 GitHub 均如此，参见GitHub Pages 数据收集说明。托管相关数据可能在美国等地区处理，保留时间按 GitHub 的处理目的及法律义务确定，并非由我们设定固定天数；其处理方式及隐私联系渠道见GitHub 隐私声明。

七、政策更新与联系

如未来增加联网、账号、支付、广告或其他第三方服务，我们将更新本说明，并按适用要求告知您。重大变化将通过适当方式提示。
