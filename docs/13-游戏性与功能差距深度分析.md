## 二、核心缺失功能深度分析

### 2.1 ✅ 选关系统 (Puzzle Library / Level Selection) —— MVP 已实现

**现状：** 用户可从内置题库浏览、选择、游玩谜题，完成后自动保存进度并可跳转下一关。

**实现状态：**

| 层次 | 状态 | 详情 |
|------|------|------|
| 数据模型 (`PuzzleLibrary.ets`) | ✅ 已完成 | `PuzzleLibrary` / `PuzzleEntry` / `PuzzleProgress` / `LibraryStats` 接口完备 |
| 持久化层 (`PuzzleLibraryStorage.ets`) | ✅ 已完成 | library index / puzzle list / progress 的完整 CRUD，基于 Preferences |
| 内置题库加载器 (`BuiltinPuzzleLibrary.ets`) | ✅ 已完成 | 4 个难度 75 道内置题目，首次启动自动注册 |
| 题库浏览页 (`PuzzleLibraryPage.ets`) | ✅ 已完成 | 两级导航（题库列表→题目网格），进度条、星级评价、状态筛选 |
| 主页入口 | ✅ 已完成 | Index.ets 底部导航新增 📚 题库 Tab |
| 路由注册 | ✅ 已完成 | `main_pages.json` 已注册 `pages/PuzzleLibraryPage` |
| GamePage 集成 | ✅ 已完成 | 接收 `libraryId` + `puzzleIndex`，完成后回写进度，"下一关"/"返回题库"按钮 |
| 题库数据文件 | ✅ 已完成 | `resources/rawfile/puzzles/` 含 4 个 SDM 文件 + manifest.json |

**仍待增强：**
- 📦 多存档支持（当前题库游戏与随机游戏共用单存档）
- 📥 外部题库导入（数据层已支持，UI 入口待实现）
- 🏆 题库全部通关成就奖励

### 2.2 🔴 每日挑战 (Daily Challenge)

**现状：** 完全缺失。竞品 (Sudoku.com, Cracking the Cryptic) 普遍具备。

**缺失影响：**
- 无日常登录动力
- 无限时排行竞技感
- 无法利用"每日一题"做留存手段

**依赖选关系统** — 每日挑战本质是"特殊的单题题库"。

### 2.3 🟡 多游戏并行管理

**现状：** 仅支持单一存档位 (`game_save` key)。一旦开始新游戏，旧存档被覆盖。

**缺失影响：**
- 用户无法同时挑战多个难度
- 选关系统需要多存档支持才能实现"中途切换关卡"
- Killer/Jigsaw 变种和标准模式无法并行

### 2.4 🟡 成就系统 / 里程碑

**现状：** 统计面板只有干巴巴的数字，无任何"徽章"或"成就解锁"反馈。

**缺失影响：**
- 统计数据缺乏情感驱动力
- 无法激励用户尝试高难度或变种模式
- 选关系统可以自然集成"全三星通关"等目标

### 2.5 🟡 技巧训练模式

**现状：** LogicSolver 支持 6 种技巧识别，但没有"专项训练"入口。

**缺失影响：**
- 用户只能在实际游戏中碰运气遇到特定技巧
- AI Coach 虽然可以解释技巧，但无结构化训练流程
- 竞品 (如 Sudoku Coach) 的技巧训练是付费核心功能

### 2.6 🟡 游戏完成后流程

**现状：** 选关模式下已实现星级评价 + "下一关"/"返回题库"；随机模式仍为原有流程。

**已实现（选关模式）：**
- ✅ "下一关"按钮（自动加载题库中下一题）
- ✅ 星级评价（★★★/★★☆/★☆☆，基于时间 + 错误数）
- ✅ "返回题库"按钮

**仍缺失：**
- 无分享按钮 (截图/Seed 分享)
- 无"重玩同题"按钮（在完成弹窗中）
- 随机模式无星级评价

### 2.7 🟢 Jigsaw 随机区域生成

**现状：** 仅有一套硬编码 regionMap，无法生成随机不规则区域。

**缺失影响：**
- Jigsaw 模式可玩性极低（永远同一个区域形状）
- 选关系统需要区域配置才能存储/恢复 Jigsaw 谜题

### 2.8 🟢 Killer 完整约束集成

**现状：** LogicSolver 中的 `CAGE_SUM` 技巧仅做了基础排除，未实现完整的笼组合分析。

**缺失影响：**
- Killer 模式的提示系统不够智能
- 难度评估不准确，无法正确分级 Killer 谜题

### 2.9 🟢 回放/复盘功能

**现状：** `GameRecord.steps` 已保存完整操作序列，但无回放 UI。

**缺失影响：**
- 历史记录的 steps 数据未被利用
- 无法学习自己的解题过程

### 2.10 🟢 自定义出题 / 编辑器

**现状：** 支持导入文本格式，但无可视化的"空白棋盘 → 手填数字 → 保存为谜题"编辑器。

## 四、优先级排序与落地建议

### P0 — 必须立即做 (选关系统核心链路)

#### 4.1 选关 MVP：内置题库 + 浏览 + 选题 + 进度

**目标：** 用户可以从预置题库中浏览、选择、游玩、跟踪进度。

**范围：**
1. `PuzzleLibraryStorage.ets` — 题库 & 进度持久化
2. `BuiltinPuzzleLibrary.ets` — 内置题库元数据 + 加载器
3. `PuzzleLibraryPage.ets` — 题库列表 + 题目列表 UI
4. `Index.ets` 改造 — 新增底部"题库"Tab
5. `main_pages.json` — 注册新路由
6. `GamePage.ets` 改造 — 接收 `libraryId` + `puzzleIndex` 参数，完成后回写进度
7. 内置 SDM 数据文件 — 至少 3 个难度各 20-50 题

**预期效果：** 用户打开 App → 点击"题库"→ 看到"入门精选 (50题) 进度: 12/50" → 点击 → 看到题目列表 → 点击第 13 题 → 进入游戏 → 完成后自动标记 ✅ → 可选"下一题"

#### 4.2 多存档支持

**目标：** 支持同时保存多个未完成游戏。

**范围：**
- `GameStorage.ets` 改为 key = `game_save_{context}` (context = "random" | "library_{id}_{index}")
- GamePage 根据来源写入不同存档
- Index "继续游戏" 列出所有存档

### P1 — 高价值功能 (选关系统增强)

#### 4.3 游戏完成后引导流程

- Victory 界面增加：评分 (时间 + 错误数 → 星级)、"下一关"、"分享 Seed"、"重玩"
- 选关返回时滚动到下一未完成题目

#### 4.4 每日挑战

- 基于日期种子 (`seed = YYYYMMDD`) 生成当日题目
- 独立统计面板 (每日完成率/连续签到天数)
- 可通过 Index 或题库页入口进入

#### 4.5 成就系统 MVP

- 内置 15-20 个成就 (首次通关/连续5胜/Expert难度通关/全题库清关等)
- `AchievementStorage.ets` + `AchievementPanel.ets`
- 在统计面板新增 Tab

#### 4.6 技巧训练模式

- 针对每种技巧 (NakedSingle → XWing) 的专项练习题库
- 只需生成"恰好需要用到该技巧"的谜题
- 与 AI Coach 结合：完成后给出技巧解说

### P2 — 中期增强

#### 4.7 Jigsaw 随机区域生成
- BFS/DFS 区域生长算法，保证每区域恰好 GRID_SIZE 个格子
- regionMap 纳入 Seed 编码，实现 Jigsaw 谜题的可复现

#### 4.8 Killer 完整约束
- LogicSolver 中实现笼组合分析 (Cage Combination Analysis)
- 难度评估纳入笼约束复杂度

#### 4.9 回放/复盘 UI
- 基于 `GameRecord.steps` 的步进式回放
- 可暂停、快进、标记关键步骤

#### 4.10 完成评价与排行
- 星级评价 (★★★)：基于完成时间 / 错误次数 / 提示使用次数
- 本地排行榜 (按题库/难度)

### P3 — 远期规划

- 在线每日排行榜 (需后端)
- 多人对战 (分布式能力)
- 自定义出题编辑器
- OCR 拍照导入
- 跨平台适配 (ArkUI-X 真正落地)
- 12×12 / 16×16 完整支持

## 八、总结

### 当前优势
1. **手势输入系统** — 行业独创，是核心差异化
2. **Seed 可复现** — 可做社交分享基础
3. **三态笔记** — 超越竞品的候选数管理
4. **AI Coach** — HarmonyOS 生态独有
5. **工程质量** — V2 状态管理 + Worker 后台生成 + 完整持久化
6. **选关系统** — 内置题库 + 进度追踪 + 星级评价 + 下一关连续游玩

### 最大短板
~~选关系统的缺失~~已通过 MVP 解决。当前最大短板转移至：
- **多存档支持** — 题库游戏与随机游戏共用单存档，无法同时保存多局
- **每日挑战** — 竞品普遍具备的日常留存手段
- **成就系统** — 缺少长期激励和里程碑目标
